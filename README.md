### ✨ Mis Proyectos Destacados

Aquí te presento algunos de mis trabajos más relevantes:

* **API para Consulta de Datos (Go):**
    Una API diseñada para la consulta de datos eficiente en bases de datos, siguiendo los principios SOLID y una arquitectura en 3 capas.
    * [Repositorio](https://github.com/Dilan-has/clientes_grupo_proteger-api)

* **Front para la API de Datos (Vue, Node):**
    Frontend intuitivo que permite interactuar con la API para consulta de datos, proporcionando una experiencia de usuario fluida.
    * [Repositorio](https://github.com/Dilan-has/clientes_grupo_proteger)

* **Simulador de Redes (Python, Tkinter):**
    Simulador gráfico interactivo desarrollado en Python, ideal para fines educativos y para comprender el funcionamiento de redes.
    * [Repositorio](https://github.com/Dilan-has/network-simulator)

* **Identificación de Espectros para Imágenes Satelitales (Python):**
    Aplicación que realiza la identificación de espectros en imágenes satelitales, devolviendo un resultado con la capa espectral resaltada para análisis.
    * [Repositorio](https://github.com/Dilan-has/satelital_image_spectral_identifier)

* **Dashboard para Consultar Datos de Futbolistas (Node.js):**
    Dashboard interactivo que permite consultar estadísticas y datos de futbolistas mediante el consumo de una API externa.
    * [Repositorio](https://github.com/Dilan-has/Proyectos/tree/main/P_Statics)

* **Pokedex (JavaScript):**
    Una Pokedex interactiva que consulta la información detallada de los Pokémon a través del consumo de una API dedicada.
    * [Repositorio](https://github.com/Dilan-has/Proyectos/tree/main/Pokedex)
